# Tada! 桌面小助手 · 前端展示版 v0.1

更新时间：2026-11-19。技术：Electron 45.3.4 + React 19.3.1，esbuild 本地构建。

## 怎么打开

双击本目录的 `启动 Tada.vbs`。启动后，屏幕右下角只出现小团子，点击展开任务卡。也可以在此目录运行 `npm run desktop`。

浏览器展示：运行 `npm run preview`，打开 http://127.0.0.1:4174 。浏览器展示包含模拟桌面与求职演示用的“小步记录”；真正桌面版只显示小团子和独立任务卡。

## 已实现

- 透明无边框小团子，顶部悬停出现拖动手柄，可拖动。
- 点击展开任务卡；减号或 Escape 收起面板。
- 托盘菜单可展开、暂时隐藏小团子或退出；点击托盘图标切换任务面板。
- 按需置顶；默认不置顶、不主动弹出任务面板、不发通知、不播放声音、不开机自启。
- 一句话任务输入、预设微行动、手动第一步、编辑、再小一点。
- 开始、分心恢复、暂停、小步完成、继续下一步和温柔庆祝。
- 本机保存任务、完成记录和偏好。浏览器版可浏览小步记录。
- 动效默认关闭；可开启缓慢呼吸，尊重系统减少动态效果设置。

## 试用路线

点小团子 → 选“整理作品集” → 帮我找第一步 → 再小一点 → 开始 → 我分心了 → 接着做这一步 → 完成。关闭程序后再打开，可接回最近的任务状态。

## 这一版的边界

这是可运行的前端与桌面交互 Demo，没有真实模型调用；预设内容在界面标注为“示例模式”。不会读取其他应用、监测注意力或自动判断分心。默认从桌面右下角启动，目前拖动位置不跨次保存。尚未制作安装包、代码签名、开机启动或跨设备同步；未做长期后台运行和内存基准测试。

Windows 的显示缩放、多屏切换和全屏应用可能影响透明窗口行为，本次已验证本机启动、窗口交互与恢复；不承诺所有设备表现一致。

## 文件与数据保留

当前可运行源码在本目录；`../desktop-v0.1` 保留初稿、依赖、下载文件与校验过程，不要移动它：本目录的 `node_modules` 与 `runtimes` 以目录链接复用其中的依赖与 Electron 运行时。

任务与偏好：`data/companion-history.jsonl`，每次保存追加一个快照；不覆盖历史。测试使用独立 smoke 日志。每次构建使用 `builds/` 下的新目录，每次桌面会话数据在 `work/electron-sessions/` 新增目录。浏览器存储使用 IndexedDB 的追加记录，与桌面版分别保存，不跨模式同步。本版没有清空、删除和自动清理操作，长期使用会增长存储。

## 验证

- `npm test`：6 项状态与数据逻辑检查。
- `node tests/browser.mjs`：先启动浏览器预览；检查输入、缩小、启动、恢复、刷新、完成、记录、偏好、收起展开和移动端溢出。
- PowerShell 中 `$env:TADA_SMOKE='1'; npm run desktop`：桌面自动检查；以独立日志验证窗口开合、任务流、保存、重载、置顶、藏到托盘及恢复，完成后退出。正常使用另开终端启动，避免继承测试变量。
- 2026-11-19 已通过以上检查，并目视核验浏览器、窄屏和真实 Electron 面板截图。

依赖以追加方式下载和解压，未执行第三方安装脚本；Electron 运行时使用镜像下载，并以从官方发布页面取得的 SHA-256 校验。后续开发也应保留历史版本，不运行清理或删除指令。

Electron 的进程隔离、受限桥接和权限设置参考[官方安全指导](https://www.electronjs.org/docs/latest/tutorial/security)。
