# Tada! 品牌视觉规范 v0.1

日期：2026-11-18。状态：设计提案，尚未通过目标用户验证。配套方向板见 `../assets/brand-board-v0.1.png`。

## 1. 品牌核心

产品名：Tada!。中文主张：每一小步，都值得庆祝。

一句话介绍：当你知道要做什么，却很难开始或重新接上时，Tada! 陪你找到眼前可做的一小步。

Soft：颜色柔和、边角圆润；Playful：轻微表情和完成反馈；Calm：稳定布局、明确入口、可控制的提示。可爱是陪伴层，清楚可用是基础层。

本版不把 ADHD 人群当成审美一致的群体。“奶油色与小团子让人更愿意开始”是待验证假设；后续测试可提供更简洁的外观。产品是执行支持工具，不承诺诊断、治疗或改善临床症状。

## 2. 色彩系统

| Token | 色值 | 用途 |
| --- | --- | --- |
| background | #FFF8EE | 奶油页面底色 |
| surface | #FFFFFF | 输入、内容卡片 |
| text | #493B36 | 标题、正文、按钮文字 |
| text-muted | #75645C | 辅助说明，仍须通过对比度检查 |
| primary | #F2B880 | 杏桃主按钮，配深色文字 |
| primary-hover | #EAA86C | 悬停与按下 |
| sage | #DDE8D8 | 完成、温柔陪伴背景 |
| lilac | #E8E0F2 | 休息、恢复辅助背景 |
| border | #D8C9BA | 装饰分隔；不能单独承担控件识别 |
| focus | #795548 | 键盘焦点、输入边界 |

浅色强调块上使用深色文字，不直接使用白字。普通文字对比度目标至少 4.5:1；大字与重要控件边界分别按 WCAG 2.2 AA 对应标准检查。状态同时给文字或图标，不能仅靠颜色。方向板是概念图，实际页面上线前逐状态检查。

## 3. 字体与排版

中文：优先系统字体 PingFang SC / Microsoft YaHei；拉丁文字：系统 sans-serif，暂不引入远程字体。Tada! 字标先用圆润粗体排版作为占位，独立标志后续设计。

字号建议：正文 16px、辅助说明 14px、卡片标题 20px、页面标题 28–32px。正文行高 1.6；少用长段落和全大写。8px 间距体系，主要卡片内边距 24px，移动端 20px；主卡片圆角 24px，按钮圆角 16px。

主要可点击区域至少 44×44px；输入框常驻可见标签，不只依赖占位提示。键盘可完成主流程，焦点清晰；缩放后允许滚动，不截断核心操作。

## 4. 小团子吉祥物

形体：一颗奶油色、略不对称的软团子，短小手脚、两点眼睛、一条小嘴；杏桃腮红。避免持续跳动、闪光和大量装饰。角色名称暂不定，文件中称“小团子”。

| 场景 | 表情与行为 | 配套文字 |
| --- | --- | --- |
| 首页等待 | 安静坐着 | 今天想先动哪一小步？ |
| 正在行动 | 小团子安静陪伴，默认静态 | 只看眼前这一步。 |
| 分心回来 | 轻轻挥手，不显示失落表情 | 欢迎回来，我们接着这一小步。 |
| 完成小步 | 短暂微笑或小星星 | Tada! 这一小步完成啦。 |
| 暂停 | 盖小毯子或闭眼 | 可以先歇一下，进度留在这里。 |

动效仅在用户操作后发生，建议 150–250ms；支持系统减少动态效果设置和产品内静态模式。角色永不因未完成任务哭泣、生气或责备用户。

## 5. 交互组件

- 每个主要页面一个高强调主按钮；“再小一点”“稍后再做”以次级方式展示。
- 首页：一行任务输入 + 一个主按钮；历史任务折叠在下方，不把计划表铺满首页。
- 微行动卡：只突出当前动作；后续步骤可展开，初次不超过三步。
- 行动页：保留“完成这一步”和“我分心了”；提供暂停与返回，计时器属于后续可选能力。
- 恢复卡：显示原任务、上一步及下一步，用户不必凭记忆重建上下文。
- 庆祝：卡片内确认，不弹全屏烟花，不强制分享、积分或连续天数。
- 隐藏历史与折叠卡片仅改变可见性，不丢弃原始记录。

## 6. 文案规范

说具体动作，不给人格评价；承认暂停是选择；鼓励可以略过。输入标签用“想做的事”，占位提示用“例如：开始整理我的作品集”。

| 情境 | 建议文案 | 避免 |
| --- | --- | --- |
| 开始 | 我们先找一小步 | 你必须马上行动 |
| 太难 | 还太大？再缩小一点 | 这已经很简单了 |
| 分心 | 刚才在整理作品集。先打开文档就好。 | 你又走神了 |
| 未完成 | 先放在这里，想继续时再回来 | 今天又失败了 |
| 失败响应 | 这次没生成成功。可以重试，也可以自己写一步。 | 系统异常！ |
| 完成 | 你写下了项目名，这一步已经完成。 | 超越了 99% 的人 |

## 7. 依据与限制

W3C 认知无障碍补充指导支持清晰内容、稳定定位和由用户控制打扰。这是通用设计依据，不证明此套配色、角色或功能对所有 ADHD 用户有效。补充指导不等同于 WCAG 合规认证。

- [帮助用户保持专注](https://www.w3.org/WAI/WCAG2/supplemental/objectives/o5-user-focus/)
- [限制打扰](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o5p01-minimal-interruptions/)
- [清晰易懂的内容](https://www.w3.org/WAI/WCAG2/supplemental/objectives/o3-clear-content/)
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
